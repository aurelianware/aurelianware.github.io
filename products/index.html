Product

Cloud Health Office.

The source-available core admin and compliance platform for health plans. It deploys beside QNXT, Facets, or HealthEdge, meets CMS-0057-F first, and can take over the core one function at a time. Evaluation lives on cloudhealthoffice.com.

Product site ↗ Source on GitHub ↗

Shipped capabilities

CapabilityStatus and evidence
ONC Inferno conformance Six kits pass nightly on synthetic data: US Core, CARIN Blue Button, Da Vinci Plan-Net, Bulk Data, Da Vinci PDex member match, Da Vinci DTR. CRD and PAS kits are not run yet. Not certification. Results
CMS-0057-F FHIR APIs Patient Access, Provider Access, Payer-to-Payer, Provider Directory, and Prior Authorization, with per-API acceptance status and remaining gaps published. Compliance status
Core integration A daily file drop beside QNXT and Facets: CARIN CPCDS extracts, 834 enrollment, prior authorizations, and fee schedules. Live core adapters are optional and scoped per plan.
CPCDS import and export Claims data loads from and exports to the CARIN Common Payer Consumer Data Set format.
Texas Medicaid APR-DRG and EAPG pricing, encounter submission and reconciliation, and Texas UMCM reports, tested on synthetic data. Texas compliance
Deployment Helm into a Kubernetes cluster in the plan’s own cloud, so PHI stays inside the plan’s boundary.

No health plan runs Cloud Health Office in production yet. We publish failures alongside passes.

How it is sold

An annual subscription license priced per member per month, in three layers: Foothold, Domain cutover, and Core. Implementation and onboarding come with the license. See the business model.
